Option 1 — IBM Plex Mono / Plex Sans hybrid instrument

A retrofuturist mono for chrome and state labels (session rows, CommandState, connectivity×activity badges, code), a readable humanist sans for message bodies and markdown. IBM Plex family shares a design language across mono and sans — they pair coherently. Plex has a technical-instrument character that fits operator-console without being sterile.

RESOLVES the markdown tension: mono chrome + readable sans body. Plex Mono carries the instrument-panel voice; Plex Sans carries long-form reading.

Option 2 — Space Grotesk / Newsreader / JetBrains Mono editorial

A geometric grotesque for chrome and UI, a readable serif (Newsreader) for message bodies and long-form markdown, JetBrains Mono for code and state. The editorial three-stack: grotesque chrome gives the operator-console discipline, the serif body makes markdown reading genuinely beautiful on mobile (serifs aid long-form legibility at small sizes). Most differentiating for the markdown-readable differentiator; pairs naturally with the Swiss/Editorial palette.

RESOLVES the markdown tension maximally: serif body is the best mobile reading experience. Three faces is more to manage, but the payoff is the differentiator.
