Option 1 — Nostromo/LCARS hybrid dark-first · warm

Amber CRT phosphor and beige instrument-panel warmth, disciplined by LCARS geometric blockwork. The operator-console aesthetic with cinematic seriousness — "self-hosted infrastructure that takes itself seriously." Dark-first; light mode is warm cream/parchment, not white.

The warmth lives in the amber; the chrome is still hard operator-console. Status reads as phosphor on black, not as decoration.

Option 2 — Soviet cybernetics system-follow · institutional

Vermilion red + cream + industrial gray, constructivist geometric type. The aesthetic of Mir control rooms and OGAS — Cold-War serious-machinery with institutional gravity. Less warmth than Nostromo, more institutional weight. Distinctive without being decorative; the red is earned signal, not garnish.

The control plane for machinery that matters. Red is reserved for terminal/failure and the single accent; it is not scattered across the chrome.

Option 3 — Swiss/Editorial hybrid light-first · disciplined

Strict grid, rigorous typographic hierarchy, one accent, generous whitespace. The operator console as a well-set document — status-forward through type weight and position, not color. Light-first; the best pole for mobile markdown readability by default. Could carry a retrofuturist accent (amber state labels on the Swiss grid) if you want to blend.

Calm instrument, not glowing console. Trust that the operator can read state without color screaming — the typography does the work.
