The model-vs-provider split, made visible: a session runs a model through a provider. token-commune is one provider (pooled); ZAI/Kimi/OpenAI direct are others. The session strip always shows provider+model+context; the usage-window cell's link target depends on which provider — a token-commune pool resource, or a direct-provider window resource. Both resource kinds live in the Resources destination because both materially govern agent availability (the resource plane's admission rule).
