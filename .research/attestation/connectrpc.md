# Attestation: Connect RPC home page

## Summary

Connect RPC presents itself as a Protobuf-powered API approach that works with plain HTTP clients, gRPC clients, web browsers, and generated clients in multiple languages. The page says TypeScript clients stay close to the Fetch API and that APIs are defined using Protocol Buffers.

## Key passages

1. From the home page examples:

> Use it with Curl ... Supports any HTTP client ... Plain HTTP

2. From the production/compatibility sections:

> Compatible with gRPC ... Connect servers handle gRPC-Web requests natively, without a translating proxy.

3. From "Familiar primitives":

> TypeScript clients stay close to the `fetch` API and integrate cleanly with popular UI frameworks.

4. From "No boilerplate":

> Define your APIs using Protocol Buffers ... Connect handles server-side routing, serialization, and compression, and it generates idiomatic clients in Go, TypeScript, Swift, Kotlin, Dart, and Python.
