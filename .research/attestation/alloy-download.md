# Attestation: Alloy download page

## Paraphrased summary

The Alloy download page describes Alloy as a self-contained executable, identifies the latest released Alloy version linked from the page, shows the jar invocation for the graphical tool, and mentions temporal model-checking tool dependencies.

## Key passages

{1} The page says Alloy is a self-contained executable including the Pardinus/Kodkod model finder, SAT solvers, the standard Alloy library, and tutorial examples. It says the same jar can be incorporated into other applications as an API and includes source code. Source-internal anchor: opening paragraph of download page.

{2} The page says to execute Alloy, double-click the jar file or type `java -jar org.alloytools.alloy.dist.jar` in a console. Source-internal anchor: opening paragraph of download page.
