# Attestation: TypeBox README

## Summary

TypeBox presents itself as a TypeScript-focused runtime type system that creates in-memory JSON Schema objects and infers TypeScript types from them. Its README says the generated schematics are designed to match TypeScript static checking and can be runtime-checked with standard JSON Schema validation. It also frames TypeBox as useful for validating wire data in REST and RPC services.

## Key passages

1. From the overview:

> TypeBox is a runtime type system that creates in-memory JSON Schema objects that infer as TypeScript types. The schematics produced by this library are designed to match the static type checking rules of the TypeScript compiler.

2. From the overview:

> TypeBox offers a unified type that can be statically checked by TypeScript and runtime checked using standard JSON Schema validation.

3. From the overview:

> It can be used as a simple tool to build up complex schematics or integrated into REST and RPC services to help validate data received over the wire.
