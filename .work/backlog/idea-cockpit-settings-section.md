# Cockpit settings section (first: tool-call visibility toggle)

Operator idea from dogfooding (2026-07-27): a settings section in the
cockpit. First requested setting: hide tool-call messages from the
transcript by default — the chat view should show prompts and agent text;
tool traffic collapses behind a "show tool calls" toggle for debugging.
Presentation-layer only (transcript fidelity in the core is untouched; this
is a view filter).

Future settings candidates: transcript density, streaming on/off, adapter
diagnostics panel visibility. Mockup-first per convention when picked up
(`.mockups/screens/`).
