## Test-tempfile root-cause fix (the sharp lesson)

`test-tempfile-hygiene` was marked "done" but shipped only an *opt-in* wrapper (`scripts/test-rust` sets `TMPDIR`). Direct `cargo test` / CI / worktree runs bypassed it → leaked `.tmp*` SQLite triples → filled `/tmp` to 100% → killed two drains. Diagnosed, filed `test-tempfile-root-cause-scoping`, fixed in two layers:
1. `patchbay-test-support` crate with a `#[ctor]` that scopes `TMPDIR` at binary load (`ca1d4cc`) — but only covers test binaries that link it.
2. **`.cargo/config.toml [env] TMPDIR` + `build.rs`** (`e0573b5`) — the universal layer covering *every* test binary including new ones; proven in production (the final 3.25h drain ran with `.tmp* = 0` throughout). A disk monitor ran as a safety net.

## Sharp lessons

- **"Ready" ≠ "design-complete."** Dependency resolution is necessary, not sufficient. The pre-drain adversarial review was the gate that prevented implementing against ungrounded designs on the highest-stakes items.
- **The `thorough` review weight earns its cost** — multi-pass convergence caught a registration-forgery path, retry bugs, a signal-cleanup hazard, and the leak itself. Single-pass would have missed them.
- **Scope-consolidation must carry detail forward, not paraphrase it away** (the `8e2e006` lossy consolidation destroyed finding detail that two reviewers then re-derived from code).
- **The agent mesh turns cross-project blockers into coordinated dependencies** — the token-commune mutation-arc question resolved in one exchange.
- **Test-infra fixes must be universal, not opt-in** — and "done" is premature until the root cause (not a mitigation) is closed.
